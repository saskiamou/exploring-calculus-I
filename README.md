# Calculus Explorer

Calculus Explorer is a C++ program that organizes Calculus I topics and their functions using a doubly linked list.

> **Status:** In development. Source code is being added; this README will be updated as features are completed.

## About the project

I proposed and designed Calculus Explorer as my semester project for **COSC 2436, Programming Fundamentals III (Data Structures)**, taught by Prof. Steven Schneider at San Jacinto College in Fall 2026. Students could choose from suggested project ideas or propose their own, and this one is my own idea.

The project connects two courses I'm taking this semester: it applies the data structures from COSC 2436 to the material from **MATH 2413, Calculus I**.

## Core design

- **Language:** C++
- **Main data structure:** a doubly linked list that holds Calculus I topics and the functions that go with each one
